## PaliGemmaDataset
（介于作业上传大小的限制数据集和从处理后的dataset没有包含到上传到作业版本的文件夹中）

用于预处理 **CASIA-OLHWDB2.0-2.2** 中的整页文本数据

├── __pycache__/
├── data/

│   ├── WPTT2.1-Test/
│   ├── WPTT2.1-Train/
│   ├── WPTT2.2-Test/
│   └── WPTT2.2-Train/
├── batch_process.py
└── data.py

运行脚本：
````shell
python batch_process.py
````
